## Модели
| Модель | Где используется | Доступ |
|---|---|---|
| Gemma 4 26B A4B | план агента; резервный критик | API организаторов |
| GLM-5.3-Flash | интерпретация события (основной писатель); резерв для ответов | API организаторов |
| Qwen3.6 35B A3B | ответы на уточняющие вопросы; резерв для плана, писателя и исследовательских вопросов | API организаторов |
| DeepSeek-V4.1-Flash | вопросы о взаимосвязях и трендах по всей ленте | API организаторов |
| Kimi-K2.6 | критик-проверяющий (самопроверка); резервный писатель | API организаторов |
| Qwen3-VL-30B-A3B-Instruct | расшифровка графиков и сканов в PDF-материалах банка (опционально) | API организаторов |

Доступ ко всем моделям идёт по одному ключу команды; модель выбирается в каждом запросе.
Используются только модели из Приложения 3 кейса; вызов других моделей блокируется кодом (`modelAllowed` в llm.go).
Внешние AI-сервисы и готовые агентные фреймворки не используются: планирование, инструменты, RAG, ранжирование
и самопроверка реализованы командой.

Опционально (по умолчанию выключено): BAAI/bge-m3 (MIT) через Ollama для эмбеддингов (`EMBEDDING_PROVIDER=bge`).
По умолчанию используется собственная реализация TF-IDF без моделей.

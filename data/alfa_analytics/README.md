# Аналитика Альфа-Банка

Материалы кейса (Приложение 2) — файлы `.pdf`, `.docx`, `.md` или `.txt` в этой папке.

PDF кейса — сканы без текстового слоя. Для них в `_text/` лежат расшифровки страниц:

```
# Заголовок
Дата: 2026-09-11
Автор: ...
Файл: ALFA-Macro_Insights-Policy_Rate_11Sep.pdf
<!-- page 1 -->
текст страницы…
```

Загрузчик сопоставляет PDF и расшифровку по полю «Файл». Расшифровка без PDF рядом тоже загружается.
Новый скан без расшифровки: включите `ANALYTICS_VISION_OCR=true` (страницы распознает Qwen3-VL) или добавьте файл в `_text/`.

Если в папке нет ни одного материала, используются синтетические заглушки из `_synthetic/`.

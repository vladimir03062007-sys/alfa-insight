# Данные о компаниях (Приложение 1 кейса)

- `df_Uid_data_hack.csv` — юридические лица (85,5 тыс.);
- `df_Fid_Uid_link_hack.csv` — связанные физические лица (12,5 тыс. связей);
- `df_Uid_payment_hack.csv` — платежи между компаниями (1,38 млн).

Разделитель и BOM определяются автоматически. Другой каталог можно указать переменной `COMPANY_DATA_DIR`.
